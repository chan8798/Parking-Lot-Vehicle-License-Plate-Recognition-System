# Parking-Lot-Vehicle-License-Plate-Recognition-System
cvp folder 
  what is best.pt file?
   -> The `best.pt` file in the `cvp` folder contains the trained YOLO26s model for Korean license plate detection.
  what is find_plate_debug.py?
   ->find_plate_debug.py detects the license plate region of a vehicle captured by a parking lot entrance or exit camera.
   ->Specify the path to the input image inside `detect_plate()`. For example, the following code processes the image located at the specified path.
   ->When this file(find_plate_debug.py) is executed, a result image file is generated.
  what is find_plate_number_dbug.py?
   ->find_plate_number_debug.py reads the license plate number from the result image generated by find_plate_debug.py.
  It is recommended to run `find_plate_debug.py` first, followed by `find_plate_number_debug.py`.
